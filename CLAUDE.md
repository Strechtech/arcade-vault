# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Arcade Vault**: Online gaming platform for playing games and competing for points. Uses **Spec Driven Design** (see `/spec` and `/spec-impl`).

## Tech Stack

- **Next.js 16.3.1** (breaking changes from prior versions — see node_modules/next/dist/docs/)
- **React 19.2.8**
- **TypeScript 5** (strict mode)
- **Tailwind CSS 4**
- ESLint with Next.js core web vitals + TypeScript rules

## SKILL for Frontend
Usa siempre /frontend-design, para diseñar la interfaz del usuario

## Architecture

**App Router**: All pages/routes live in `app/` directory. `app/layout.tsx` is the root layout.

**Path aliases**: `@/*` points to repo root (tsconfig.json).

**Styling**: Tailwind CSS with globals.css. Dark mode supported via class strategy.

**Design methodology**: Spec-Driven Design (reference: https://github.com/Klerith/fernando-skills).


## Key Files

- `app/` — Next.js app directory (routes, layouts, pages)
- `tsconfig.json` — Path aliases, TypeScript config
- `next.config.ts` — Next.js config
- `AGENTS.md` — Breaking changes warning for Next.js 16
- `.next/` — Build output (ignored from git)

## Notes

- Next.js 16 has breaking changes. When implementing features, consult docs in `node_modules/next/dist/docs/` before writing code.
- The `AGENTS.md` file is auto-generated by `next dev`; changes to it are uncommitted by default.
- When using skills: `npx skills@latest add Klerith/fernando-skills` (per README).
